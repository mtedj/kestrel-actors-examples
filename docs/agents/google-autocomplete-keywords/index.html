Google Autocomplete - Keyword Suggestions & Seed Expansion

Get Google autocomplete keyword suggestions from seed queries, country and language. One row per suggestion: seed, expanded query, text, position and locale. Optional a-z seed expansion, text filters and new-only monitoring. Parsed queries are billed even when no suggestions remain.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.4; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/google-autocomplete-keywords",
  "input": {
    "queries": [
      "keyword research"
    ],
    "maxSuggestionsPerSeed": 3,
    "maxRequests": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
