Agoda Reviews Scraper — Hotel Reviews, Guest Reviews & Ratings

Agoda hotel reviews by hotel name, URL or id, with the Booking.com reviews Agoda shows. One row per review: 0-10 rating, title, text, positives, negatives, language, stay dates, room, reviewer country, photos, hotel reply, source. Free filters before billing: max score (negative reviews), text only.

Understand the output before you run

Three row types share one dataset: review (one guest review, charged), hotel (context for a property, free) and status (per property, free).

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.23; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/agoda-reviews-scraper",
  "input": {
    "startUrls": [
      "https://www.agoda.com/tivoli-avenida-liberdade-lisboa/hotel/lisbon-pt.html"
    ],
    "maxReviewsPerHotel": 3,
    "reviewsSort": "most_recent"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
review$0.005One guest review of an Agoda property: 0-10 rating (and out of 5), rating word, title, text, positives and negatives, language and the original text where Agoda translated it, review and stay dates, room, reviewer name and country, helpful votes, photos, source (Agoda or Booking.com) and the hotel's reply with date (row keys rating, rating_5, rating_text, title, text, positives, negatives, language, original_text, review_date, check_in, check_out, room_type, reviewer_name, reviewer_country, helpful_votes, images, source, response, response_date): $5 per 1,000 reviews. Not charged: hotel rows, status rows, reviews removed by maxRating or requireText, a property given twice (name, URL and id of one hotel are read once), properties with no reviews, names or URLs that match nothing, bad input. No start fee; proxy and compute are included in the event price. Agoda pages about 100 reviews at a time; a mid-size hotel has a few hundred, a busy hostel over a thousand. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
