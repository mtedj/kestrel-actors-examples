Understand the output before you run

Two row types share one dataset: item (one eBay listing from a search page or an item page, charged) and status (one per keyword or URL, free).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.1.9; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/ebay-search-scraper",
  "input": {
    "queries": [
      "mechanical keyboard"
    ],
    "pages": 1,
    "maxResultsPerQuery": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
item$0.004One delivered active eBay listing: $4 per 1,000 listings ($0.004 each; up to 60 search rows/page). Item-page details are currently unreliable; search rows do not include item specifics, and successful search does not guarantee detail rows. Blocked item pages are not charged. Search row keys: item_id, title, url, price, currency, list_price, discount_pct, shipping_cost, condition, buying_format = buy_it_now or auction, bids, time_left, best_offer, units_sold, watchers, seller, seller_feedback_pct, location, image. Active listings only; UK and sold/completed modes are unsupported. Not charged: empty searches, listings outside minPrice/maxPrice, duplicate item IDs within one run, status rows, refused pages, bad input. No start fee; proxy and compute are included in the event price. If a separate item-URL run delivers a detail row, it is charged again at $0.004; failed attempts are free. The run stops at the Apify run option maxTotalChargeUsd, never above it.
