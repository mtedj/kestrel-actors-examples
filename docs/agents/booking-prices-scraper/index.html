Booking.com Scraper — Hotel Prices & Availability by Date

Booking.com prices and availability by date for destinations or hotels by URL, name or id. One row per hotel: stay total, nightly rate, taxes, free cancellation, breakfast, stars, review score, sold out. Optional room rates. Filters before billing: max price, star class. Price tracking, comp sets.

Understand the output before you run

One row per property with its price for the stay, optional room-rate rows, and one status row per target.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.2.5; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/booking-prices-scraper",
  "input": {
    "locationQueries": [
      "Lisbon"
    ],
    "maxHotelsPerQuery": 3,
    "checkIn": "30 days",
    "nights": 1,
    "adults": 2,
    "currency": "USD",
    "sortBy": "price"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
hotel$0.004One delivered Booking.com hotel row with a non-null reported stay price: $4 per 1,000 rows. Row keys include hotel_id, name, price_total, price_nightly, currency, taxes_fees_excluded, taxes_included, free_cancellation, no_prepayment, breakfast_included, room_name, check_in and check_out. Reported prices and badges are search-result indicators, not a verified payable total or complete same-rate policy/eligibility contract; missing badge data can become false. Unpriced/sold-out hotel rows, filtered rows, duplicates, status rows, bad input and failed/empty searches are not charged. No start fee; proxy and compute are included. maxTotalChargeUsd is an Apify run option; the run stops at that ceiling.
room$0.002One delivered matching room/rate block from Booking's returned search result, only when includeRooms=true: $2 per 1,000 rows. Row keys include hotel_id, room_id, room_name, occupancy, meal_plan, meal_plan_id, policy_group_id, price_total, currency, price_original, original_currency, free_cancellation_until and only_x_left. Optional source fields, including price, can be null. original_currency belongs to the block originalPrice; it is not verified as hotel currency. Cancellation text is not a complete penalty/payment contract. These blocks are not exhaustive inventory. rooms_listed counts returned blocks before the run spending cap; no separate room cap. No charge when includeRooms=false. No start fee; proxy and compute included.
