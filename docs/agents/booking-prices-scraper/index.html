Booking.com Scraper — Hotel Prices & Availability by Date

Booking.com prices and availability by date for destinations or hotels by URL, name or id. One row per hotel: stay total, nightly rate, taxes, free cancellation, breakfast, stars, review score, sold out. Optional room rates. Filters before billing: max price, star class. Price tracking, comp sets.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.2.2; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/booking-prices-scraper",
  "input": {
    "locationQueries": [
      "Lisbon"
    ],
    "maxHotelsPerQuery": 3,
    "checkIn": "30 days",
    "nights": 1,
    "adults": 2,
    "currency": "USD",
    "sortBy": "price"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
hotel$0.004One Booking.com property priced for your dates and guests: its lowest stay price, flags, rating and location (row keys hotel_id, name, url, stars, review_score, review_count, address, latitude, longitude, distance_from_center, price_total, price_nightly, currency, taxes_fees_excluded, free_cancellation, no_prepayment, breakfast_included, room_name): $4 per 1,000 hotels. Not charged: sold-out or unpriced properties (delivered free with Booking's alternative dates), properties maxPrice or minStars remove, a property reached twice in one run, destinations or names that match nothing, status rows, bad input. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
room$0.002One room and rate combination Booking.com matched to your stay, only when includeRooms is true: room name, occupancy, meal plan, stay total and nightly rate, hotel-currency price, free-cancellation deadline, "only X left" message (row keys hotel_id, hotel_name, room_id, room_name, occupancy, meal_plan, price_total, price_nightly, currency, price_original, original_currency, free_cancellation, free_cancellation_until, only_x_left, check_in, check_out): $2 per 1,000 rows. Not charged when includeRooms is false (default), and never for sold-out properties. The hotel row's rooms_listed is the number of room rows that property adds. No start fee; proxy and compute are included in the event price.
