Hotel Rate Parity Checker — OTA Price Comparison

Check hotel rate parity on Google Hotels by name or URL. Each stay compares OTA and official site rates: nightly price, cancellation, booking link, cheapest source, spread and direct booking rate. Find parity violations: who undercuts the hotel and by how much. Available rates only; rate shopping.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.8; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/hotel-rate-parity",
  "input": {
    "hotels": [
      "https://www.google.com/travel/hotels/entity/ChkIhLCQwvjO2IYWGg0vZy8xMXE0bTZieDkyEAE"
    ],
    "checkIn": "30 days",
    "nights": 1,
    "currency": "USD"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
parity$0.01One hotel and stay with every booking site's rate (Booking.com, Expedia, Agoda…), cheapest and dearest, spread, median, official-site rate and who undercuts it (row keys hotel_name, entity_id, check_in, sources, min_source, min_price, max_source, max_price, spread_pct, median_price, official_price, undercut_by, undercut_pct): $10 per 1,000 rows (1 cent per hotel and stay). One row per hotel and stay however many sources (about 18, 4 to 36): 10 hotels × 7 dates (sweepDays 6) = 70 rows = $0.70. Not charged: hotels with no rate, rows under minSpreadPct, names that match nothing, duplicates, status rows. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
