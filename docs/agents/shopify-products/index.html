MCP + API · kestrel/shopify-products

Shopify Products - Prices, Variants, SKUs & Availability

Get Shopify product catalogs from store URLs or a collection. Each product includes prices, currency, variants, SKUs, availability, images, vendor and descriptions. Filter titles, vendors and available products before billing. Exclude known IDs for new products. No login or API key needed.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.12; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/shopify-products",
  "input": {
    "storeUrls": [
      "https://kith.com"
    ],
    "maxProductsPerStore": 3,
    "maxResults": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
