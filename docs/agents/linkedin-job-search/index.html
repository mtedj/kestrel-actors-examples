Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.8; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/linkedin-job-search",
  "input": {
    "queries": [
      "data engineer"
    ],
    "maxResultsPerSource": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
page-parsed$0.005One successfully parsed search page: $5 per 1,000 pages. Billed even when filters, duplicates or monitoring leave zero rows. Failed requests and unrecognized pages are not charged. Separate delivered-row fee applies. No start fee; proxy and compute included. maxTotalChargeUsd is an Apify run option; before another page the budget must cover a page plus one row.
job$0.001One delivered job: $1 per 1,000 rows. Row keys: id, job_id, title, url, company, company_url, location, posted_date, posted_text, salary_text, logo_url, description. Filtered, duplicate, unchanged or excluded rows have no row fee. Parsed pages cost $0.005 each, even with no delivered rows. No start fee; proxy and compute included. Stops at the maxTotalChargeUsd run-option budget. With includeDetails=true this event is replaced by job-with-description, not added to it.
job-with-description$0.004One delivered job with a successfully fetched full description: $4 per 1,000 enriched jobs. Replaces the $0.001 job event, not an add-on. Row keys include description, seniority, employment_type, job_function and industries; unavailable criteria stay null. Failed descriptions have no job fee. Parsed search pages cost $0.005 each, including filtered or unchanged checks. No start fee; proxy and compute included. maxTotalChargeUsd is a run option, not input.
