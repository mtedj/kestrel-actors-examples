Understand the output before you run

Two row types share one dataset: product (one search result or chart entry, charged) and status (per keyword or category, free).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.4.3; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/amazon-search-scraper",
  "input": {
    "queries": [
      "wireless earbuds"
    ],
    "pages": 1,
    "skipSponsored": true,
    "maxResultsPerQuery": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
product$0.004One product from a search page or a chart page (row keys asin, title, url, query, chart, category, position = slot on the page for a keyword search, rank = chart rank for Best Sellers and New Releases, page, price, currency, rating, ratings_count, image, sponsored, domain): $4 per 1,000 products. Measured: a search page carries about 20 organic products plus sponsored ones; a chart page 30. Price is null where the page shows none. Not charged: rows removed by skipSponsored, minRating or maxResultsPerQuery, an ASIN already delivered by another keyword, searches with no results, failed searches, status rows. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd).
