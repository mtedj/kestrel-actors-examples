Google Flights Scraper — Airfare Prices, Fares & Price Tracking

Get Google Flights prices by route, dates, cabin and passengers. One row per itinerary: price, airline, times, duration, stops, layovers, CO2. One-way or round trip; nonstop and business class fares. Sweep dates for a fare calendar. Schedule daily flight price tracking to build price history.

Understand the output before you run

Two row types share one dataset: flight (one itinerary for a route, date and cabin) and status (one per route and date; never charged).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.1.5; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/google-flights-prices",
  "input": {
    "routes": [
      "LIS-LHR"
    ],
    "departDate": "30 days",
    "sweepDays": 0,
    "currency": "EUR",
    "market": "pt"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
flight$0.005One flight itinerary for your route, dates, cabin and passengers: price for all passengers, airline, departure and arrival times, duration, stops, layovers, CO2 (row keys route, origin, destination, depart_date, return_date, seat, adults, price, currency, airline, stops, depart_time, arrive_time, duration_minutes, layovers, co2_kg, rank, google_url): $5 per 1,000 itineraries. Usually 10 to 35 rows per route and date; maxResultsPerSearch caps them. Not charged: empty or failed searches, duplicates (an itinerary two overlapping searches both return is billed once), status rows, refused inputs. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
