TripAdvisor Reviews Scraper & API: Hotel Reviews, Guest Reviews

TripAdvisor hotel reviews and TripAdvisor ratings by URL, id or name. One row per review: bubbles, title, text, six sub-ratings, stay date, trip type, reviewer, photos, management response. Free hotel row: rating, review count, city ranking. Filters: negative reviews, new reviews only. 24 languages.

Understand the output before you run

One row per guest review (charged), plus a free hotel context row and a free status row per hotel and language.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.2.5; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/tripadvisor-reviews-scraper",
  "input": {
    "startUrls": [
      "https://www.tripadvisor.com/Hotel_Review-g189158-d4509998-Reviews-Memmo_Alfama_Hotel-Lisbon_Lisbon_District_Central_Portugal.html"
    ],
    "languages": [
      "en"
    ],
    "maxReviewsPerHotel": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
review$0.005One TripAdvisor hotel review: 1-5 bubbles, six sub-ratings, management response (row keys review_id, rating, title, text, sub_ratings, language, original_language, stay_date, trip_type, reviewer_name, photos, helpful_votes, response): $5 per 1,000 reviews, once per language site; maxReviewsPerHotel 100 (default) caps a hotel at $0.50 per language. Not charged: the hotel row (rating, review count, city ranking, address, amenities), reviews removed by maxRating, tripTypes, sinceDate, requireText or includeTranslated, hotels with no reviews, unknown ids, duplicate targets, failed pages and status rows.
