Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
page-parsed$0.008One successfully parsed search page: $8 per 1,000 pages. Billed even when filters, duplicates or monitoring leave zero rows. Failed requests and unrecognized pages are not charged. Separate delivered-row fee applies. No start fee; proxy and compute included. maxTotalChargeUsd is an Apify run option; before another page the budget must cover a page plus one row.

Stops at the maxTotalChargeUsd run-option budget. Monitoring rows include previous_rank and rank_change; positive rank_change means improvement. New rows have previous_rank=null.
