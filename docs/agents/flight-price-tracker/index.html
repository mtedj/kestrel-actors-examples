Flight Price Tracker — Cheapest Day to Fly & Fare Calendar

Track Google Flights fares across 1–60 departure dates per route. One row per day: cheapest price, airline, stops and rank. Flight price calendar for one-way or round trips, with nonstop and max-price filters. Schedule snapshots for price history; threshold rows do not send notifications.

Understand the output before you run

Two row types share one dataset: fare (one per route and departure day — that day's cheapest itinerary) and status (one per route; never charged).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.1.3; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/flight-price-tracker",
  "input": {
    "routes": [
      "LIS-LHR"
    ],
    "departDate": "30 days",
    "days": 1,
    "currency": "EUR",
    "market": "pt"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
fare$0.004One route and departure day: that day's cheapest Google Flights itinerary with price, airline, stops, times, duration, layovers, CO2 and its rank in the window (row keys route, origin, destination, depart_date, return_date, seat, price, currency, airline, stops, depart_time, arrive_time, duration_minutes, layovers, co2_kg, rank_in_window, cheapest_in_window, itineraries_seen): $4 per 1,000 days. At most one row per route and day, so a 30-day window on one route is at most 30 rows. Not charged: days with no fare, days over your maxPrice (filtered before billing), failed days, status rows, refused inputs. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
