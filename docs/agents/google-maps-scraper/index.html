Understand the output before you run

Two row types share one dataset: place (one Google Maps place, charged) and status (one per search, free).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.3.3; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/google-maps-scraper",
  "input": {
    "searches": [
      "coffee shop"
    ],
    "locations": [
      "Austin, TX"
    ],
    "maxPlacesPerSearch": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
place$0.004One Google Maps place delivered as a full row, every detail included: phone, website, rating, review count, hours, address parts, coordinates (row keys place_id, cid, google_maps_url, name, category, phone, website, rating, review_count, opening_hours, address, street, city, postal_code, country_code, lat, lng, is_closed_permanently). $4 per 1,000 places. All filters are free and run BEFORE this charge: places your filters reject, duplicates, places an earlier monitored run delivered, empty or failed searches and unknown locations cost $0. No start fee, proxy and compute included in the event price; charged count always equals delivered rows. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
contact-found$0.003When enrichContacts (or onlyWithEmail) is on: $3 per 1,000 places where an email or social/WhatsApp link is found on the place's own website, in addition to the $4 per 1,000 base place fee (row keys emails, email_primary, phones_from_site, contact_page_url, facebook, instagram, linkedin, x, youtube, tiktok, whatsapp, enrichment_status). No website, unreachable website, phone-only findings or no contact found = no contact fee. At the historical 50% contact yield, 1,000 enriched places cost about $5.50 total ($4 base + $1.50 contacts); yield is not guaranteed. With onlyWithEmail, each delivered place has an email and costs $0.007 total: 50 delivered places cost $0.35; places without an email are omitted and free. Proxy and compute are included in these event prices.
