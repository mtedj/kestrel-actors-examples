Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.7; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/website-screenshot-capture",
  "input": {
    "startUrls": [
      "https://example.com"
    ],
    "width": 1440,
    "height": 900,
    "fullPage": true,
    "maxResults": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
