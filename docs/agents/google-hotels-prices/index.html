Google Hotels Prices Scraper & API - OTA Rates, Hotel Details

Google Hotels API: hotel prices by city, hotel name or URL for your dates. One row per hotel: nightly rate, stay total, taxes, deals, availability, rating. Optional OTA rates (Booking.com, Expedia, Agoda, official site): rate parity, price comparison, price tracking. Free: address, phone, amenities.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.9.8; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/google-hotels-prices",
  "input": {
    "queries": [
      "hotels in Lisbon"
    ],
    "checkIn": "30 days",
    "checkOut": "32 days",
    "adults": 2,
    "currency": "USD",
    "maxHotels": 3,
    "includeOffers": true,
    "offerLevel": "sources",
    "maxOffersPerHotel": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
hotel$0.004One hotel with its lowest nightly rate, stay total and taxes for your dates (row keys name, entity_id, hotel_id, stars, rating, reviews, lat, lng, nightly, total, taxes, fees, total_with_taxes, currency, source, check_in, check_out, google_url): $4 per 1,000 hotels. Address, phone, amenities and photos (includeDetails; keys address, phone, place_id, amenities, photos) ride on this row at no extra charge. Not charged: sold-out or unpriced hotels, duplicates, hotels your filters remove, empty or failed searches, hotel names that match nothing, status rows. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
offer$0.002One booking site's rate for one hotel and stay (Booking.com, Expedia, Agoda, official site…) with free-cancellation flag and link (row keys entity_id, hotel_id, name, source, official, room, nightly, total, currency, link, partner_url, free_cancel, free_cancel_until_date, max_guests, lowest, check_in, check_out): $2 per 1,000. Measured: about 18 rows per hotel (4 to 36) with offerLevel "sources", about 65 (up to 150) with "rooms". Not charged when includeOffers is false; maxOffersPerHotel caps the rows per hotel. Failed offer lookups are free.
