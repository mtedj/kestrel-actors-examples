Understand the output before you run

Three row types share one dataset: hotel (lowest nightly rate and stay total per hotel), offer (one booking source's rate for a hotel and stay), status (per place or property and stay; never charged).

Assemble a hotel price comparison

The dataset is flat: type=hotel, type=offer and type=status. Join hotel and offer rows by entity_id + check_in + check_out, keeping currencies separate. hotel_id may be null. Individual booking sources and links belong to the offer rows: source, official, nightly, total, currency, link, partner_url.

Keep includeOffers=true for booking-site comparisons. A positive maxOffersPerHotel keeps the cheapest offers and may omit the official site; a missing direct offer does not prove rate parity. Check status rows for source errors. With ten hotels and eight offers each, listed event charges are at most $0.20; use a separate run budget and report early stopping.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.9.11; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/google-hotels-prices",
  "input": {
    "queries": [
      "hotels in Lisbon"

    "checkOut": "32 days",
    "adults": 2,
    "currency": "USD",

    "maxOffersPerHotel": 3

    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
hotel$0.004One hotel with its lowest nightly rate, stay total and taxes for your dates (row keys name, entity_id, hotel_id, stars, rating, reviews, lat, lng, nightly, total, taxes, fees, total_with_taxes, currency, source, check_in, check_out, google_url): $4 per 1,000 hotels. Address, phone, amenities and photos (includeDetails; keys address, phone, place_id, amenities, photos) ride on this row at no extra charge. Not charged: sold-out or unpriced hotels, duplicates, hotels your filters remove, empty or failed searches, hotel names that match nothing, status rows. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
