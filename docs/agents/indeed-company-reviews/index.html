Indeed Company Reviews Scraper - Employee Reviews, Ratings

Scrape Indeed company reviews (employer reviews) by name or URL. One row per employee review: rating, 5 sub-ratings, text, pros, cons, job title, location, employer reply. Free: employer ratings, industry, size. Filters: rating, date, job title, location. Only-new mode for monitoring. 44 countries.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.2.1; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/indeed-company-reviews",
  "input": {
    "companies": [
      "https://www.indeed.com/cmp/Google/reviews"
    ],
    "countries": [
      "us"
    ],
    "maxReviewsPerCompany": 3,
    "sort": "newest"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
