Kurzurlaub Reviews Scraper - Hotel Reviews, Gästebewertungen

German Kurzurlaub.de hotel reviews by URL or hotel id. One row per guest rating: 1-6 score, category scores (room, service, food, wellness, location, value), title, comments, date. Free hotel row: stars, city. Free filters: complaints, only new since a date. Kurzurlaub Bewertungen, Hotelbewertungen.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.7; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/kurzurlaub-reviews-scraper",
  "input": {
    "startUrls": [
      "https://www.kurzurlaub.de/hotel/rhein_lahn_taunus/hachenburg/parkhotel-hachenburg.html"
    ],
    "maxReviewsPerHotel": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.
