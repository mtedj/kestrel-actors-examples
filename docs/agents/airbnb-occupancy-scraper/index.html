Airbnb Occupancy Rate Scraper — Availability & Nightly Rates

Estimate Airbnb occupancy from listing availability calendars by place or listing ID. One row per listing and month: available and blocked-or-booked days, occupancy %, minimum stay and sampled nightly rate. For rental market research and comps; blocked nights cannot be separated from bookings.

Understand the output before you run

Row types in one dataset: occupancy (one per listing and calendar month — days available vs blocked or booked, occupancy %, minimum stay, a sampled nightly rate), listing (optional, free), status (per place, URL or listing id; never charged).

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.8; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/airbnb-occupancy-scraper",
  "input": {
    "locationQueries": [
      "Lisbon, Portugal"
    ],
    "maxListingsPerQuery": 3,
    "months": 1
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
