Understand the output before you run

Two row types share one dataset: product (one product's details from its public page, charged) and status (per ASIN or URL given, free).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.3.3; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/amazon-product-scraper",
  "input": {
    "asins": [
      "B0CHWRXH8B"
    ],
    "domain": "com"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
product$0.004One product's details from its public page (row keys asin, title, brand, price = buybox price, list_price, currency, availability, in_stock, prime, rating, ratings_count, 5_star_pct to 1_star_pct = histogram, images, features = bullets, description, category, details = details table, bsr = Best Sellers Rank, sold_by, variations_count): $4 per 1,000 products, one page fetch each. No buybox price or no rank still delivers the row (price or bsr null); inStockOnly or maxPrice skip paying for those. Not charged: products dropped by inStockOnly or maxPrice, unknown ASINs (404), pages Amazon blocked, duplicates, status rows. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd).
