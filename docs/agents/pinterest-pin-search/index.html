Pinterest Pin Search - Image URLs & Destination Domains

Search Pinterest pins by keywords. One row per pin: title, description, image URL, dimensions, destination URL, domain, board name and date. Filter text, image orientation and destination domains; collect only new pins. Parsed pages are billed even when filters or monitoring return no rows.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.5; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/pinterest-pin-search",
  "input": {
    "queries": [
      "home office"
    ],
    "maxPinsPerQuery": 3,
    "maxPagesPerQuery": 3,
    "maxRequests": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
