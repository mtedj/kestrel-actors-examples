Airbnb Scraper — Prices, Availability Calendar & Listings

Airbnb vacation rental listings and prices by place, URL or ID for your dates and guests. Rows: nightly rate, stay total, rating, bedrooms, Superhost, photos. Optional 24-month availability calendar and reviews. Free details: amenities, house rules, host, price breakdown. No daily calendar prices.

Understand the output before you run

Row types in one dataset: listing (price for the dates, rating, location, optional details), calendar (day-by-day availability with an occupancy summary), review, status (per place or listing; never charged).

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
listing$0.005One Airbnb listing with its price for your dates and guests (row keys price_total, price_nightly, price_nightly_effective, currency, rating, reviews_count, is_superhost, url): $5 per 1,000 listings. Amenities, house rules, host and the price breakdown (includeDetails) ride on this row at no extra charge. Not charged: listings Airbnb cannot price for the dates, duplicates, unknown places, empty searches, status rows. Without dates every listing row counts, at its default displayed price. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd).
calendar_month$0.002One month of day-by-day availability for one listing (available, check-in and check-out allowed, minimum and maximum nights per day): $2 per 1,000 months, so a 12-month calendar is $0.024 per listing; the row also carries occupancy for the next 30, 90 and 365 nights. Not charged: calendarMonths 0 (the default), failed calendars, months beyond your spending limit (the row is trimmed to the months billed).
review$0.003One guest review with rating, text, Airbnb's translation and original language, date, reviewer name and location, stay type and host reply: $3 per 1,000 reviews, up to maxReviewsPerListing per listing (default 0 = none, maximum 200). Not charged: listings with no reviews, failed review fetches. For a rating filter, every review of a listing or more than 200, use kestrel/airbnb-reviews-scraper.
