Understand the output before you run

Three row types share one dataset: hotel (one property with its cheapest rate for the stay, charged when priced), calendar (one check-in date of a property's price calendar, charged when priced) and status (per destination or property, free).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.1.4; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/agoda-prices-scraper",
  "input": {
    "locationQueries": [
      "Lisbon"
    ],
    "checkIn": "30 days",
    "nights": 1,
    "adults": 2,
    "maxHotelsPerQuery": 3,
    "sortBy": "price_low",
    "currency": "USD"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
