Agoda hotel prices and availability for destinations or hotels by URL, id or name. One row per hotel: nightly and total price, taxes, free cancellation, rooms left, stars, guest score, sold out. Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.1.4; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/agoda-prices-scraper",
  "input": {
    "locationQueries": [
      "Lisbon"
    ],
    "checkIn": "30 days",
    "nights": 1,
    "adults": 2,
    "maxHotelsPerQuery": 3,
    "sortBy": "price_low",
    "currency": "USD"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
hotel$0.004One Agoda property's cheapest rate for your dates and guests (row keys hotel_id, hotel_name, stars, review_score, review_count, area, country, latitude, longitude, price_nightly, price_nightly_with_taxes, price_total, price_total_with_taxes, crossed_out_price, available_rooms, cancellation, free_cancellation_until, breakfast_included): $4 per 1,000 hotels. Not charged: sold-out properties (free rows with includeSoldOut), properties maxPrice, minStars, minReviewScore or freeCancellationOnly remove, a property reached twice in one run, destinations or names that match nothing, status rows, bad input. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
calendar_day$0.002One check-in date of a named hotel's price calendar (calendarDays, up to 60 dates from checkIn): per-night and stay price at your nights and adults priced live for that date, rank_in_window (1 = the cheapest date), Agoda's Low/Normal/High trend word where it has one (row keys hotel_id, hotel_name, check_in, check_out, nights, adults, currency, price_nightly, price_total, trend, rank_in_window, cheapest_in_window): $2 per 1,000 dates. Not charged: dates Agoda has no price for (skipped), hotels from destination searches (no calendar is read for them), bad input. No start fee; the same maximum-cost stop applies.
