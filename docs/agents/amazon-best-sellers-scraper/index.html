Understand the output before you run

Two row types share one dataset: product (one chart entry with its rank, charged) and status (per category, free).

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.2.3; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/amazon-best-sellers-scraper",
  "input": {
    "categories": [
      "electronics"
    ],
    "chart": "bestsellers",
    "pages": 1,
    "maxResultsPerCategory": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
product$0.004One entry of a Best Sellers or New Releases chart (row keys rank, asin, title, url, chart, category, page, price, currency, rating, ratings_count, image, domain): $4 per 1,000 entries. A chart page is 50 ranks, so one category's Top 100 (pages 2, the default) is 100 rows, $0.40. Price is null where the chart prints none; an entry whose tile Amazon withholds still comes with rank, ASIN and URL. Not charged: entries removed by minRating or maxResultsPerCategory, an ASIN already delivered from another category, categories that return nothing, failed categories, status rows. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd).
