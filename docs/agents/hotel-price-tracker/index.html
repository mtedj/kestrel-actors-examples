Hotel Price Tracker — Google Hotels Price History & Alerts

Track hotel prices on Google Hotels by name or URL across up to 60 dates. Each hotel/date row has lowest nightly rate, total, cheapest source and link, cancellation and cheapest date. Price calendar and rate monitoring; scheduled runs build price history. maxPrice filters rows for price-drop alerts.

Understand the output before you run

Two row types share one dataset: rate (one property and check-in date with the lowest rate across every booking source, the cheapest source and the date's rank in the window; charged) and status (one per property; never charged).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.7; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/hotel-price-tracker",
  "input": {
    "hotels": [
      "https://www.google.com/travel/hotels/entity/ChkIhLCQwvjO2IYWGg0vZy8xMXE0bTZieDkyEAE"
    ],
    "checkIn": "30 days",
    "days": 1,
    "nights": 1,
    "currency": "USD"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
rate$0.004One hotel and check-in date: the lowest nightly rate across every booking site Google Hotels lists, stay total, cheapest source with booking link, official-site rate, free-cancellation flag and the date's rank in the window (row keys hotel_name, entity_id, check_in, check_out, currency, price, total, source, source_url, official_price, free_cancellation, rank_in_window): $4 per 1,000 rows. At most one row per hotel per check-in date (days, up to 60): 2 hotels × 30 dates = 60 rows = $0.24. Not charged: dates with no rate (sold out), dates over maxPrice, names that match nothing, duplicates, status rows. No start fee; proxy and compute are included in the event price. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
