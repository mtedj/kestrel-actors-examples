Trustpilot customer reviews by domain or URL. Each review: rating, title, text, dates, country, verified label, company reply. Free: TrustScore, star histogram, email, phone. Understand the output before you run

One row per Trustpilot review (charged), plus a free company context row and a free status row per company.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.1.3; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/trustpilot-reviews-scraper",
  "input": {
    "companyDomains": [
      "www.booking.com"
    ],
    "maxReviewsPerCompany": 3,
    "sort": "most_recent",
    "languages": "all"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
