Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.1.2; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/trustpilot-reviews-scraper",
  "input": {
    "companyDomains": [
      "www.booking.com"
    ],
    "maxReviewsPerCompany": 3,
    "sort": "most_recent",
    "languages": "all"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Not charged: the company row (TrustScore, star histogram, email, phone), status rows, reviews Trustpilot's star, date, language, verified and keyword filters skip (never fetched), reviews before sinceDate or without text (requireText), a company given twice, companies with no reviews or no Trustpilot profile, bad input.
