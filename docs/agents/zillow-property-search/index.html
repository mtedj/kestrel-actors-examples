Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.9; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/zillow-property-search",
  "input": {
    "searchUrls": [
      "https://www.zillow.com/austin-tx/"
    ],
    "maxResultsPerSource": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
page-parsed$0.02One successfully parsed search page: $20 per 1,000 pages. Billed even when filters, duplicates or monitoring leave zero rows. Failed requests and unrecognized pages are not charged. Separate delivered-row fee applies. No start fee; proxy and compute included. maxTotalChargeUsd is an Apify run option; before another page the budget must cover a page plus one row.
property$0.002One delivered property: $2 per 1,000 rows. Row keys: id, zpid, listing_type, title, url, address, street, city, state, zipcode, price, price_text. Filtered, duplicate, unchanged or excluded rows have no row fee. Parsed pages cost $0.02 each, even with no delivered rows. No start fee; proxy and compute included.
