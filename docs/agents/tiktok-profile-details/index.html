TikTok Profiles - Followers, Likes & Bio Links

Read public TikTok profiles by username or profile URL. One row per profile: followers, following, total likes, videos, bio, website and verified status. Filter followers, bio text or websites; skip saved IDs or hashes for repeat monitoring. Profile data only; no videos or follower lists.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.3; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/tiktok-profile-details",
  "input": {
    "usernames": [
      "tiktok"
    ],
    "maxResults": 3,
    "maxSources": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
