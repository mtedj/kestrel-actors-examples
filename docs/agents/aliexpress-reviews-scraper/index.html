AliExpress Reviews Scraper: Product Reviews, Ratings & Feedback

Scrape AliExpress product reviews by URL or item id: star rating, buyer feedback translated into 16 languages, buyer photos, country, SKU variant. Date, keyword and star filters, new-review monitoring, free sentiment analysis. For dropshipping product research. No login. API and MCP ready.

Understand the output before you run

One row per AliExpress buyer review (charged), plus a free product context row and a free status row per target.

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.1.9; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/aliexpress-reviews-scraper",
  "input": {
    "productUrls": [
      "https://www.aliexpress.com/item/1005006255429323.html"
    ],
    "maxReviewsPerProduct": 3,
    "reviewsFilter": "all"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
