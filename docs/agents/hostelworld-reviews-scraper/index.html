Hostelworld Reviews Scraper - Hostel Guest Reviews, Ratings

Get Hostelworld hostel and backpacker reviews by property URL or ID. Each review includes score, safety, location, staff and cleanliness ratings, text, owner reply, group type, age, nationality and date. Free hostel row: address, lowest price. Filters: negative reviews, dates and group type.

Understand the output before you run

One row per hostel guest review (charged), plus a free hostel context row and a free status row per target.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.9; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/hostelworld-reviews-scraper",
  "input": {
    "startUrls": [
      "https://www.hostelworld.com/hostels/p/15529/home-lisbon-hostel/"
    ],
    "maxReviewsPerProperty": 3,
    "reviewsSort": "-date"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
review$0.004One Hostelworld guest review: 0-100 score with seven sub-ratings, the text, the hostel's reply, group type, age band, trip types, nickname and nationality (row keys review_id, rating, sub_ratings, text, owner_comment, group_type, age_group, trip_types, reviewer_nickname, reviewer_country, review_date): $4 per 1,000 reviews. Not charged: reviews removed by minRating, maxRating, groupTypes, sinceDate or requireText, duplicate targets, hostels with no reviews, unknown ids, hostel rows, status rows. No start fee; proxy and compute are included in the event price. Hostelworld pages 50 reviews at a time and a busy hostel has a few thousand: maxReviewsPerProperty caps the rows per hostel. The run stops at the maximum cost per run you set (Apify run option maxTotalChargeUsd), never above it.
