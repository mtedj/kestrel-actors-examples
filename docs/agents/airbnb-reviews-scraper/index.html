Airbnb Reviews Scraper — Guest Reviews, Ratings & Host Replies

Airbnb vacation rental guest reviews by URL, id or place. One row per review: rating, text, host replies, translation, language, date, reviewer, location. Lowest rated first and minRating keep only negative reviews (complaints) and bill only those. For sentiment, reputation, competitor research.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.2.6; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/airbnb-reviews-scraper",
  "input": {
    "locationQueries": [
      "Lisbon, Portugal"
    ],
    "maxListingsPerQuery": 3,
    "maxReviewsPerListing": 3,
    "reviewsSort": "most_recent"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
