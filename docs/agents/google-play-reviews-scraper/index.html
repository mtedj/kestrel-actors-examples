Understand the output before you run

Three row types share one dataset: review (one user review, charged), app (context for an app in a language and country, free) and status (per app, language and country, free).

Declared dataset fields and row types · Output locations and dataset links

Use the declared dataset schema for item fields; the output schema describes where results are stored. Optional fields may be null or absent. If an integration shows a sampled schema without an optional field, check this declaration, the Actor instructions and actual returned rows before concluding that the field is unsupported.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.6; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/google-play-reviews-scraper",
  "input": {
    "appIds": [
      "com.whatsapp"
    ],
    "languages": [
      "en"
    ],
    "countries": [
      "us"
    ],
    "maxReviewsPerApp": 3,
    "sort": "most_recent"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
review$0.004One Google Play review (row keys review_id, app_id, language, country, rating = 1-5, text, author, thumbs_up, app_version, review_date, reply_text = developer reply, reply_date, url): $4 per 1,000 reviews. Not charged: app rows (Google Play rating, rating count, category, price), status rows, reviews removed by minRating, maxRating, sinceDate or requireText, reviews Google itself skips when one star value is asked (never fetched), a review listed under two languages or countries (delivered once), apps with no reviews, unknown packages, failed jobs, bad input. No start fee; proxy and compute are included in the event price. Google answers up to 100 reviews per request. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
