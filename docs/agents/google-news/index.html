Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.11; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/google-news",
  "input": {
    "queries": [
      "artificial intelligence"
    ],
    "maxArticlesPerQuery": 3,
    "maxResults": 3
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
