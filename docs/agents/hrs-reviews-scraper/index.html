HRS Reviews Scraper - Hotel Reviews, Guest Reviews, Ratings

Get HRS hotel reviews by URL or hotel ID. Each guest review includes 0-10 rating, 12 category scores, positives, negatives, hotel reply, traveller type, stay dates, language and text. Free hotel row: stars, address. Filters: complaints, negative reviews, business travel, German. Hotelbewertungen.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.0.8; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/hrs-reviews-scraper",
  "input": {
    "startUrls": [
      "https://www.hrs.com/en/hotel/10520"
    ],
    "maxReviewsPerHotel": 3,
    "reviewsSort": "most_recent",
    "proxyConfiguration": {
      "useApifyProxy": true,
      "apifyProxyGroups": [
        "RESIDENTIAL"
      ]
    }
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
review$0.004One commented guest rating of an HRS hotel: 0-10 score, 12 category scores, positives, negatives, the hotel's replies, traveller type, age group, stay dates, language and text (row keys review_id, rating, votes, positives, negatives, hotel_reply, traveller_type, age_group, arrival_date, departure_date, language, text, review_date): $4 per 1,000 reviews. Not charged: reviews removed by maxRating, travellerTypes, languages or requireText, duplicates, hotels with no commented ratings, unknown ids, hotel rows, status rows. No start fee; proxy and compute are included in the event price. A busy hotel has 50-150 commented ratings; maxReviewsPerHotel caps the rows per hotel. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
