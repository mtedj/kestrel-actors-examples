Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.3.1; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/booking-reviews-scraper",
  "input": {
    "startUrls": [
      "https://www.booking.com/hotel/pt/memmo-alfama.html"
    ],
    "maxReviewsPerHotel": 3,
    "reviewsSort": "most_recent"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.

Pricing and limits

Current listed event prices in USD. Some Actors charge for successful source checks even when no output rows match. The event descriptions below define those differences.

EventUSD eachWhat is charged
review$0.005One guest review of a Booking.com hotel: 1-10 score (and out of 5), title, liked and disliked text, language, review and stay dates, nights, room, traveller type, reviewer name and country, helpful votes, photos and the property's reply (row keys rating, rating_5, title, positives, negatives, text, language, review_date, check_in, check_out, nights, room_type, traveler_type, reviewer_name, reviewer_country, helpful_votes, photos, response): $5 per 1,000 reviews. Not charged: hotel rows (category ratings, review count), status rows, reviews removed by maxRating, sinceDate or requireText, reviews Booking's language, traveller-type and keyword filters skip (never fetched), a hotel given twice, hotels with no reviews, names or URLs that match nothing, bad input. No start fee; proxy and compute are included in the event price. About 4 reviews in 10 are score-only. The run stops at the maximum cost per run you set when starting it (Apify run option maxTotalChargeUsd), never above it.
