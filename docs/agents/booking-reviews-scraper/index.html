Booking.com Reviews Scraper — Hotel Reviews, Guest Reviews

Booking.com guest reviews by URL, name or id. One row per review: score, title, liked/disliked, language, review/stay dates, room, traveller type, country, photos, property reply. Free hotel row: score, 7 category ratings. Free filters: language, keyword, max score (negative reviews), since date.

Start with a small sample

Use call-actor with the JSON below. The $0.25 run ceiling is separate from the Actor input and may stop the sample early. Change the target to match your request. This input validates against build 1.3.1; it is not a promise that the source has matching rows today.

{
  "actor": "kestrel/booking-reviews-scraper",
  "input": {
    "startUrls": [
      "https://www.booking.com/hotel/pt/memmo-alfama.html"
    ],
    "maxReviewsPerHotel": 3,
    "reviewsSort": "most_recent"
  },
  "callOptions": {
    "maxTotalChargeUsd": 0.25,
    "timeout": 300
  },
  "waitSecs": 30
}

After completion, use get-dataset-items with storages.datasets.default.id. If still running, poll get-actor-run using the returned runId. Check status rows and errors before treating an empty dataset as no matches.
