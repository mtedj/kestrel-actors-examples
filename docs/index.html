kestrel Apify actors — documentation

30 scrapers for travel prices, guest reviews, ecommerce and app stores, each one an Apify actor. Billing is Actor-specific: delivered rows and, for some tools, successful source checks even when no rows match. Every date input takes a relative value like 30 days, so a schedule never goes stale, and none of them needs an API key on the site being read. Each page below is the full reference for one actor — every input, every output field, a real row, working code and its honest limits.

Start here

Install the client, set your Apify token, call an actor by name:

pip install apify-client          # or: npm i apify-client
export APIFY_TOKEN=...            # console.apify.com/account/integrations
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("kestrel/agoda-reviews-scraper").call(run_input={
    "hotelNames": ["Park Hyatt Tokyo"], "maxReviewsPerHotel": 200,
    "reviewsSort": "most_recent",
})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    if row["type"] == "review":
        print(row["rating"], row["reviewer_country"], row["text"][:80])

The same call in JavaScript and curl, for every actor, is in the examples repository — together with importable n8n workflows.

How billing works

Read each Actor’s pricing events. Some tools charge for successful source checks even when no rows match. For pay-per-event Actors, set maxTotalChargeUsd in run options, or callOptions for the MCP call-actor tool. Use input result and request limits to bound work.

FAQ

What am I charged for?

Billing is Actor-specific. Some tools charge for successful source checks even when no rows match. Read the pricing events and set a pay-per-event run budget. Each actor's pay-per-event schema is on its own page.

Do I need an API key for the site being read?

No. The actors read public pages and the JSON endpoints those pages call, with no login and no account on the source site. The only credential is your Apify token.

Will a scheduled run go stale?

No. Date inputs take relative values — checkIn: "30 days", sinceDate: "7 days" — so a schedule keeps meaning the same thing every morning.

Can I export to CSV or Excel?

Yes. Every run writes an Apify dataset, exportable to CSV, Excel, JSON or XML from the Console, or over the API by appending ?format=csv to the dataset items endpoint.

Can I call these from n8n, Make or an AI agent?

Yes. Each actor is callable through Apify's integrations, over the REST API, and from an AI agent through Apify's MCP server. The examples repository carries importable n8n workflows.

What happens when a run hits a spending limit?

The run stops delivering rather than handing you rows it could not charge for, so the row count in your dataset and the count on your invoice always agree.
