## Run one small sample

Choose an Actor below, read its current contract and replace the sample targets with yours. Set `APIFY_TOKEN` in your environment using your account's secret manager or local shell configuration; keep it out of source files and URLs.

- **Python:** `python -m pip install 'apify-client>=3.1,<4'`, then `python examples/ACTOR.py`. The SDK returns a typed Run object; use `run.default_dataset_id`.
- **JavaScript:** `npm install 'apify-client@^2'`, then `node examples/ACTOR.js`.
- **REST:** install `curl` and `jq`, then `bash examples/ACTOR.sh`.

Each example sets a **$0.25 per-run charge ceiling** outside the Actor input and a five-minute run timeout. These sample limits can stop work early. The free hotel-reputation checker has no event fee; check your account's platform usage costs. The REST API documents this run-limit parameter for all pricing models. Pricing remains Actor-specific: successful source checks can be billed even when no output rows match.

The examples export JSON Lines to standard output, preserve status rows and nulls, paginate datasets, and report run status on standard error. Redirect output to a file when needed. A failed run can still have partial output; a successful run can contain source errors, so inspect the Actor's status rows, logs and documented summary. After a network failure, inspect existing runs before starting another one. Actor restarts and automatic start-request retries are disabled. Python starts once through REST, then uses SDK3 to poll and export; retries on those read-only requests cannot create another run.

These inputs were checked against active cloud schemas and the client examples were tested for SDK compatibility, result pagination and failure handling. This does **not** mean all sample targets were live-run again or that source sites will always return data. Read maintenance notices before use.
